This is a developed Machine Learning based SMS classification system to identify and distinguish between spam and legitimate(HAM) messages
Performed Text preprocessing including tokenization, stop-word removal and text cleaning
Used Python libraries such as Pandas,Numpy,Scikit-learn and NLTK
Evaluated the model performance using accuracy, precision, recall. f1-score
app.py is the application file which is written in python 
model.pkl is the classification model which is first written in google collab the converted to pkl and brought here
spam.csv contains the dataset of spam messages used for training and testing  the model
vectorizer.pkl is where the classification is done
